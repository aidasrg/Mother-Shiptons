# Mother Shipton's Cave & Petrifying Well – Tourist Website

This package contains the complete, standalone one-page visitor guide website ready to upload to any web hosting service.

## Included Files
- `index.html`: Complete, self-contained responsive website with styling, text-to-speech audio reader, print stylesheet, and jump navigation.
- `styles.css`: Optional standalone CSS file (already embedded in `index.html` for single-file deployment).

## How to Deploy / Host
1. **GitHub Pages / Netlify / Vercel:** Simply drag and drop `index.html` or push to a repository.
2. **Traditional Web Hosting (cPanel / Apache / Nginx):** Upload `index.html` to your `public_html` or web root folder.
3. **Local Testing:** Double-click `index.html` to open directly in any modern browser (Chrome, Safari, Edge, Firefox).
